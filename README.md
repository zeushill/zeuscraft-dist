# ZeusCraft 내려받기

## ⬇ 프로그램 받기

**[최신판 받기 →](https://github.com/zeushill/zeuscraft-dist/releases/latest)**

그 화면에서 **`ZeusCraft-<버전>.zip`** (약 185MB) 하나만 받으시면 됩니다.

> **아래 `Source code (zip)` / `(tar.gz)` 는 프로그램이 아닙니다.**
> GitHub 이 모든 릴리스에 자동으로 붙이는 것으로, 이 저장소의 안내문 두 개(1KB)만 들어 있습니다.
> 잘못 받으시면 파일이 열리지 않습니다.

## 📖 설치 방법

**[설치 방법 보기 →](https://cafe.naver.com/autoworker2/123)**

사진과 함께 자세히 설명되어 있습니다. 처음이시면 이쪽을 먼저 보세요.

### 간단히 보면

1. 받은 zip 의 **압축을 풉니다**
2. 크롬 주소창에 `chrome://extensions` 를 넣고 엽니다
3. 오른쪽 위 **개발자 모드**를 켭니다
4. **압축해제된 확장 프로그램 로드** → 압축 푼 폴더를 고릅니다

이미 쓰고 계시면, 기존 폴더에 덮어쓴 뒤 확장 관리 화면에서 🔄 새로고침만 하시면 됩니다.
